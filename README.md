# AMCSET

AMCSET is a C++ project for simulating ion and electron bombardment of materials. The codebase includes a shared simulation library, a Qt-based GUI, and automated tests for validating collision and tally behavior.

## Overview

- Monte Carlo-style particle transport and energy-loss simulation
- Support for ion and electron bombardment workflows
- Material/target geometry and layer modeling
- Result tallies and output histograms
- Cross-platform build scripts for Windows and Linux
- Conan-managed dependencies and CMake-based build configuration

## Repository layout

- `common/` — core simulation logic, utilities, and generated isotope data
- `gui/` — Qt application and visualization components
- `test/` — GoogleTest-based unit/integration tests
- `visualization/` — CSV-based plotting/animation utilities
- `build/` — generated build artifacts
- `qbuild.ps1` / `qbuild.sh` — project build scripts
- `run-dev.sh` / `Dockerfile` — Linux container-based development workflow
- `conanfile.py` — Conan package definition and dependency setup

## Requirements

For a local build, you will typically need:

- CMake
- Conan 2
- A recent C++20 compiler
- Python 3
- Qt 6 dependencies (managed through Conan)

The project is configured to use Conan to install the required libraries, including Boost, GTest, glog, gflags, and Qt.

## Quick start

### Linux/macOS

From the project root:

```bash
./qbuild.sh -c -b
```

Useful commands:

```bash
./qbuild.sh -c   # install Conan dependencies
./qbuild.sh -b   # configure and build the Release target
./qbuild.sh -t   # run the CTest suite
./qbuild.sh -r   # launch the GUI
```

If you want a full default build with no arguments, the script also runs the build path by default.

### Windows (PowerShell)

From the project root:

```powershell
.\qbuild.ps1 -c -b
```

Useful commands:

```powershell
.\qbuild.ps1 -c  # install Conan dependencies
.\qbuild.ps1 -b  # build the Release target
.\qbuild.ps1 -t  # run tests
.\qbuild.ps1 -r  # run the GUI
```

The script configures a Release build and uses the Conan-generated CMake presets.

## Docker-based development

A Docker workflow is also included for a reproducible Linux environment:

```bash
./run-dev.sh
```

For a clean rebuild of the dev image:

```bash
./run-dev.sh --rebuild
```

This sets up a container with the needed system packages and Conan configuration for Qt and CMake development.

## Building details

The project uses CMake presets generated by Conan, with the build type fixed to Release unless you explicitly adjust the script or CMake configuration.

The core library target is `amcset-common`, and the GUI target is `amcset-gui`.

## Testing

The test suite is registered with CTest through the project CMake configuration. Run:

```bash
./qbuild.sh -t
```

or on Windows:

```powershell
.\qbuild.ps1 -t
```

## Notes

- The scripts are intended to keep local build setup simple and consistent across environments.
- If dependencies fail to resolve, try clearing stale Conan state and reinstalling dependencies.
- The project includes a generated `compile_commands.json` workflow for editor tooling such as clangd and IDE integrations.
